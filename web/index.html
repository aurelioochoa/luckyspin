Welcome to the house.

Five tables. An idle economy. One local save.

A casino you can build.

Lucky Spin is an open-source incremental game written in C++. Play in your terminal or browser using the same game engine and save. All money is fictional; there are no accounts, payments, or remote game services.

Your first few minutes

  1. Open Income and buy a $10 Tip Jar to earn $0.10/s.
  2. Set a comfortable bet, then try the five tables.
  3. Buy upgrades and choose a specialty to improve returns.
  4. Build income toward prestige. Spend your stars on permanent perks.

Progress stays with you.

Actions save automatically. Passive income saves every 30 seconds, and offline earnings apply when you return. Keep one game instance open to avoid competing saves. Finish blackjack hands before closing; active hands are not restored.

Keyboard shortcuts

1–5 choose a table. Tab moves between controls; Enter activates them. Esc closes a confirmation. Shortcuts pause while you type.
